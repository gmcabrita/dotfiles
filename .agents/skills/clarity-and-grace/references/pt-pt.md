# European Portuguese (PT-PT) adjustments

Use this file with `lessons.md` when the draft is in European Portuguese. The principles in `lessons.md` still apply. This file replaces its English-specific parts: examples, word lists, correctness rules, and folklore.

Write revisions in PT-PT. Do not mix Brazilian norms into the draft. Use the spelling of the 1990 Spelling Agreement (AO90) unless the draft or venue uses the old spelling; then keep it consistent.

---

## General differences from English

| Topic | English | PT-PT | Effect on coaching |
| --- | --- | --- | --- |
| Subject | Always explicit | Often null; the verb ending shows the person (*Decidimos…*) | Read the verb ending to find the character |
| Nominalization | Marks bureaucratic prose | Common and accepted in formal registers | Adjust to the register; still fix nominalizations that hide characters |
| Passive | *be* + participle | *se* passive and *ser* passive | Choose by topic and stress position (see Lesson 4) |
| Sentence length | Shorter is the norm | Longer sentences are accepted, above all in academic prose | Break a sentence when the reader loses the subject or verb, not only because it is long |
| Word repetition | Consistent terms are normal | Schools teach readers to avoid repetition | In expository text, keep one term for one concept |

## Lesson 2: Correctness (PT-PT)

**Real rules** (errors that careful readers notice):

- **Pronoun placement.** Enclisis is the default in PT-PT: *Disse-me que…*, never *Me disse* at the start of a sentence. Use proclisis after:
  - negation: *não, nunca, jamais, ninguém, nada* (*Não o vi.*)
  - subordinating words and relatives: *que, quando, se, porque, como, onde* (*Sei que o viste.*)
  - some adverbs: *já, ainda, sempre, só, também, bem, talvez* (*Já te disse.*)
  - indefinite and interrogative words: *alguém, todos, tudo, quem, porquê* (*Quem te disse?*)
- **Mesoclisis** with the future and the conditional, in formal writing: *dir-lhe-ei*, *far-se-ia*. With a proclisis trigger: *não lhe direi*.
- **Impersonal *haver* and *fazer*.** Singular: *Havia muitas pessoas* (not *haviam*); *Faz dois anos* (not *fazem*).
- ***à* / *a* / *há*.** *à* = *a* + *a*; *há* = the verb *haver* (*há dois anos*).
- **Porque / porquê / por que.** PT-PT uses *porque* for questions and answers; *porquê* at the end of a question or as a noun (*Não sei porquê.*, *o porquê*); *por que* = *pelo qual* (*o motivo por que saiu*). This differs from Brazilian use.
- **Second person singular, preterite.** *fizeste, disseste* (not *fizestes, dissestes*).
- **Se passive agreement** (normative): *Vendem-se casas.*, *Analisaram-se os dados.* With a preposition the verb stays singular: *Precisa-se de técnicos.*
- **Common word errors:** *com certeza* (not *concerteza*); *de encontro a* (against) vs. *ao encontro de* (in line with); *hás de, há de* (no hyphen in AO90).

**Optional rules** (follow the venue):

- No contraction before the subject of an infinitive: *apesar de o governo ter decidido* (normative) vs. *apesar do governo ter decidido* (common).
- AO90 vs. pre-AO90 spelling.
- Formal address in letters (*V. Ex.ª*).

**Folklore** (do not enforce):

- "Never start a sentence with *E* or *Mas*."
- "Never use the first person in academic text." Many venues accept *nós*.
- "Never repeat a word." In expository text, repeat the key term.
- "The gerund is always wrong." The gerund is correct in PT-PT (*Chegando a casa, …*; *…, reduzindo os custos*). Only the progressive *estar + gerúndio* is Brazilian (and regional in Portugal); standard PT-PT uses *estar a + infinitivo*.
- "Always avoid the passive."

## Lesson 3: Actions (PT-PT)

Nominalizations with support verbs are the main PT-PT pattern. The support verb carries no meaning; the noun carries the action.

| Pattern | Example | Revision |
| --- | --- | --- |
| Support verb + noun | *A equipa procedeu à análise dos dados.* | *A equipa analisou os dados.* |
| | *efetuar o pagamento* | *pagar* |
| | *realizar uma avaliação* | *avaliar* |
| | *fazer a gestão de* | *gerir* |
| | *dar início a* | *começar, iniciar* |
| | *tomar uma decisão* | *decidir* |
| | *ter em consideração* | *considerar* |
| | *dar resposta a* | *responder a* |
| | *levar a cabo* | the verb for the action |
| Nominalization as subject | *A intenção da comissão é auditar…* | *A comissão pretende auditar…* |
| *Existe / há* + nominalization | *Existe a necessidade de rever o plano.* | *Temos de rever o plano.* |
| Two nominalizations in a chain | *A não implementação da medida levou ao aumento dos custos.* | *Como não implementámos a medida, os custos aumentaram.* |

Keep nominalizations for the same reasons as in English: reference to the previous sentence (*Esta decisão…*), familiar concepts (*fiscalidade, latência*), or a register that requires them. In legal and administrative text, ask the user whether a formula is mandatory before changing it.

## Lesson 4: Characters (PT-PT)

- **Null subjects.** The character can live only in the verb ending. *Analisámos os dados* has the character *nós*. This is clear.
- **Ambiguity risk.** In the third person, a null subject can refer to more than one character. If two characters compete, name the subject.
- **Overuse of pronouns.** Explicit *ele, ela, eles* in every sentence sounds like a translation. Drop them when the verb ending is clear.
- **Supplying a character.** Where the draft hides the agent, use *nós* in academic text, *a equipa*, *o utilizador*, or the institution. In instructions, prefer the infinitive or the imperative. *Você* can sound impolite in PT-PT; avoid it in docs unless the house style uses it.
- **Choosing the passive:**
  - *ser* passive puts the patient first, as the topic (old information): *Os dados foram analisados pela equipa.*
  - *se* passive often puts the noun after the verb, in the stress position (new information): *Analisaram-se então três cenários.*
  - Active with a null subject is often the lightest: *Analisámos três cenários.*
- **Noun strings** are rare in PT-PT. The equivalent is a chain of *de* phrases: *o processo de revisão da política de gestão de riscos*. Unpack it with a verb: *rever a forma como gerimos os riscos*.

## Lesson 5: Cohesion (PT-PT)

- **Topic string test.** Underline the first six or seven words. If the subject is null, write the implied character next to the sentence. Check that the characters form a consistent set.
- **Repetition vs. synonyms.** Writers in Portuguese often swap synonyms to avoid repetition (*o sistema… a plataforma… a solução… a ferramenta*). In expository text this makes readers think there are several things. Keep one term.
- **Connectors.** Short connectors link old to new: *Assim, Por isso, Neste caso, Ainda assim*. Long connectors add weight without meaning: *Neste sentido, Posto isto, Face ao exposto*. Keep them short.

## Lesson 6: Emphasis (PT-PT)

- The stress position works as in English. Portuguese also allows the subject after the verb to put new information at the end: *Surgiu então um problema.*, *Faltam dois testes.*
- Verbs that present new information do this well: *surgir, existir, faltar, chegar, aparecer*.
- Move long peripheral phrases away from the end.

  *Foi decidido pela direção, na reunião de ontem, depois de longa discussão, o encerramento da fábrica.*
  → *Na reunião de ontem, depois de longa discussão, a direção decidiu encerrar a fábrica.*

## Lesson 7 and 8: Motivation and global coherence (PT-PT)

- The structure is the same: context → condition → cost → point.
- Portuguese academic and institutional texts often start with a long *enquadramento* and delay the point. Keep the context short. Put the point at the end of the introduction.
- School essays often place the thesis only in the conclusion. For expository and professional text, state it early.

## Lesson 9: Concision (PT-PT)

| Category | Examples | Revision |
| --- | --- | --- |
| Filler | *a nível de, em termos de, no âmbito de* (when vague), *de alguma forma, basicamente, no fundo, propriamente dito* | Cut, or name the real relationship |
| *de facto, efetivamente* | When there is no contrast with a prior belief | Cut |
| Phrases for words | *devido ao facto de* → *porque*; *no caso de* → *se*; *com o objetivo de / no sentido de* → *para*; *apesar do facto de* → *embora*; *no momento atual* → *agora, hoje*; *tendo em conta que* → *como* | Replace |
| Pleonasms | *há anos atrás, elo de ligação, subir para cima, encarar de frente, planear antecipadamente, surpresa inesperada, consenso geral, outra alternativa, principal protagonista, repetir de novo, adiar para depois* | Cut the redundant word |
| Metadiscourse | *Importa referir que, É de salientar que, Cumpre sublinhar que, Convém notar que* | Cut; state the claim |
| Intensifiers | *extremamente, bastante, claramente, sem dúvida, fundamental, crucial* | Cut most |
| Hedges | *parece, poderá, eventualmente, de certa forma* | Keep only for real uncertainty |

**False friend:** *eventualmente* means "possibly", not "in the end". Flag this in text translated from English.

## Lesson 10: Shape (PT-PT)

- The same diagnostics apply: long introductions, long subjects, interruptions between subject and verb.
- Portuguese allows longer sentences. Break a sentence when the reader must hold more than one open idea, or when the verb comes after many words.
- **Resumptive modifier:** *A proposta depende da cache, uma cache que só funciona quando há mais leituras do que escritas.*
- **Summative modifier:** *A latência caiu para metade, uma mudança que os utilizadores notaram num dia.*
- **Free modifier (gerund):** *A equipa reescreveu o parser, reduzindo o tempo de compilação para metade.* Correct in PT-PT. Do not chain more than one per sentence.
- Watch for chains of *que* clauses (*…que…que…que…*). Split them or turn one into a noun or a gerund phrase.

## Lesson 11: Elegance (PT-PT)

- Portuguese readers accept more rhetorical elegance. In technical text, keep it for key claims and conclusions.
- Balance and climax work the same way: order items from short to long and from less to more important.

## Lesson 12: Ethics (PT-PT)

Impersonal forms hide responsibility easily in Portuguese:

- *Foram cometidos erros.* / *Registaram-se falhas.* / *Verificou-se um atraso.*

Ask who did the action. If the reader needs to know, name the agent.

## Brazilian forms to avoid in PT-PT

| Brazilian | PT-PT |
| --- | --- |
| *estou fazendo* | *estou a fazer* |
| *Me disse que…* | *Disse-me que…* |
| *você* in docs | infinitive, imperative, or *o utilizador* |
| *usuário, arquivo, tela, time, celular, mouse* | *utilizador, ficheiro, ecrã, equipa, telemóvel, rato* |
| *fato, contato, registro, recepção* | *facto, contacto, registo, receção* |
| *econômico, gênero, Antônio* | *económico, género, António* |
| *por que* in questions | *porque* / *porquê* |
| *implementamos* (past) | *implementámos* (the accent marks the past tense) |

## Calques from English

Flag these in text written by people who work in English or in text translated from English:

| Calque | PT-PT |
| --- | --- |
| *endereçar um problema* | *resolver, tratar* |
| *aplicar para uma vaga* | *candidatar-se a* |
| *realizar* (= realize) | *perceber, aperceber-se* |
| *assumir* (= assume) | *supor, presumir* |
| *suportar* (= support) | *apoiar, ser compatível com* |
| *atualmente* (= actually) | *na verdade* |
| *eventualmente* (= eventually) | *por fim, mais tarde* |
| *baseado em* at the start of every sentence | vary the structure or name the source |
